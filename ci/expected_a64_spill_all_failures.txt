# arm64-linux corpus debt under CGF_SPILL_ALL=1.
#
# Forcing every interval to memory is the only thing that exercises the spill
# rewrite broadly, and that rewrite is where an instruction's index moves --
# the exact shape of the NZCV bug fixed in `9c98698`, which one fixture at
# one optimization level was all that caught. The ordinary lane runs at
# natural pressure, where a handful of corpus programs spill at all.
#
# Enforced EXACTLY in both directions by scripts/a64_corpus_lane.sh, the same
# as the ordinary ledger: a new failure fails the lane and so does an entry
# that starts passing. Run it with
#
#     CGF_A64_SPILL_ALL=1 CGF_A64_CORPUS_WORK=build/a64-corpus-sa \
#       CGF_A64_LEDGER=ci/expected_a64_spill_all_failures.txt \
#       sh scripts/a64_corpus_lane.sh
#
# or `make test-a64-spill-all`.
#
# EMPTY. Every finding this lane produced has been fixed; three distinct
# causes, none of them reachable by the ordinary lane:
#
# 1. A read-modify-write def took a FRESH scratch instead of the one its own
#    reload had just filled. movk is the only RMW and it exists only inside a
#    multi-instruction constant materialization, so the symptom was a silently
#    WRONG CONSTANT: `movz x16, ...; movk x17, ...` built 3.187264 where the
#    program said 3.140625. Five fixtures.
# 2. A spilled INDIRECT CALLEE was substituted with no scratch and no reload,
#    which quietly rewrote it to x0 -- `blr x0`, branching to whatever the
#    first argument left there. marshal_calls pre-colours a call's arguments
#    and result but not its callee, so it is the one value on a call that can
#    spill. One fixture.
# 3. The va_start expansion hardcoded x16 for its address computations, but
#    the va_list pointer it writes THROUGH is an operand of that very
#    instruction -- so a spilled one was reloaded into the same register and
#    destroyed before the stores. It now picks a scratch that differs from
#    the pointer. Two fixtures.
#
# Keep the lane. All three are real miscompiles that ordinary pressure can
# reach; spill-all only makes them certain.
#
# Format: <suite>/<name> [-O<level>] # <cause or observation>
